# Новогоднее письмо для Маши

Локальная открытка с анимацией конверта и сургучной печати, двусторонним письмом, подарками и ответом. Сделана для телефона; внешние библиотеки и сервисы для работы не нужны. Node.js 20 или новее.

## Запуск

```powershell
cd C:\Users\Nikita\Desktop\ng
npm start
```

Открыть http://localhost:3000. Не открывайте index.html напрямую: сохранение работает через сервер.

Чтобы сервер продолжал работать после закрытия терминала, запустите `./start-local.ps1`. Остановить этот фоновый сервер можно командой `./stop-local.ps1`. Это запуск вручную, не автозагрузка Windows. Обычный `npm start` работает, пока открыт его терминал.

Чтобы проверить с телефона, подключите его к той же Wi-Fi сети, что и компьютер, и откройте `http://IP-КОМПЬЮТЕРА:3000`. IPv4 адрес можно посмотреть командой `ipconfig`. Если Windows спросит о доступе Node.js к сети, для проверки достаточно частной домашней сети. Компьютер и сервер должны оставаться включены. При необходимости другой порт: `$env:PORT=3001; npm start`.

## Где подарки и ответы

`data/letters.jsonl` создаётся автоматически при первом сохранении. Каждая строка — отдельная запись JSON: дата в UTC, тип (`gift` или `reply`), текст, ID записи и ID письма. Открывается обычным текстовым редактором. Подарок записывается сразу после подтверждения и остаётся, даже если ответа не будет. Отрицательный ответ и выбор «Ответить лично» тоже записываются. Последний вариант после успешного сохранения открывает https://t.me/enograten.

Файл исключён из Git. Сервер не отдаёт его через сайт. Браузер хранит только случайный ID письма; при перезагрузке подарки и ответы восстанавливаются с сервера для этого ID. На другом устройстве или после очистки данных браузера будет новое письмо. При сбое сохранения окно остаётся открытым, текст не теряется, появляется ошибка. Повторная отправка того же сообщения не создаёт дубликат при потерянном ответе сервера.

Рядом с каждым подарком есть кнопка «Изменить». Она открывает сохранённый текст; после подтверждения подарок обновляется без добавления второй коробочки. Правки тоже дописываются в `data/letters.jsonl`: ID и дата создания остаются прежними, добавляется `updatedAt`. Файл сохраняет историю, а сайт показывает последнюю версию каждой записи с тем же ID.

## Публикация и сохранение на компьютере

Адрес открытки: https://nikitos812.github.io/dlya-mashi/. Ветка `main` содержит исходники, а `gh-pages` — только содержимое папки `public`. GitHub Pages отдаёт саму открытку. Данные гостей GitHub не хранит.

Подарки, правки и ответы идут через Cloudflare Tunnel на локальный Node.js-сервер и записываются непосредственно в `C:\Users\Nikita\Desktop\ng\data\letters.jsonl`. Для сохранения компьютер, интернет, сервер и соединение должны работать. Если они недоступны, форма показывает ошибку и остаётся открытой с введённым текстом; успешного сохранения без подтверждения сервера нет.

Запуск после включения компьютера:

```powershell
cd C:\Users\Nikita\Desktop\ng
.\start-public.ps1
```

Скрипт запускает сервер и фоновое соединение. Закрытие терминала не прерывает их. Для соединения используется официальный подписанный Cloudflare `cloudflared.exe` в `.deploy` (https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe). Исполняемый файл не хранится в Git.

Бесплатный Quick Tunnel выдаёт временный технический адрес `*.trycloudflare.com`. При его смене скрипт обновляет `public/config.json` и ветку `gh-pages`, используя официальный Git Credential Manager. Адрес самой открытки остаётся тем же; обновление на GitHub Pages может занять несколько минут. Это бесплатное соединение без гарантии доступности Cloudflare. Подробности: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/.

Журнал соединения: `data/public-tunnel.log`. Остановить доступ из интернета: `./stop-public.ps1`. Отдельно остановить сервер: `./stop-local.ps1`. Автозагрузка Windows не настраивалась.

Папка `data`, журналы и локальные настройки не попадают в Git. API разрешает запросы со страницы на `https://nikitos812.github.io`, а записи доступны по случайному ID письма, сохранённому в браузере посетителя. Не публикуйте файл с ответами и не передавайте ID письма посторонним.
